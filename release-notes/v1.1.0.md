## Talky 1.1.0

Talky now has a proper installer and updates itself.

- **Install:** download `Talky-win-x64-Setup.exe` (or `Talky-win-arm64-Setup.exe` on ARM PCs) and run it. No admin needed. If the .NET 10 Desktop Runtime is missing, Setup installs it first.
- **Updates:** Talky checks for new versions in the background. When one is ready you'll see **Restart now**; otherwise it installs the next time you open Talky.
- **Smaller:** the download is about 40% smaller than the 1.0 zip.
- Your chats and friends now live in `%APPDATA%\Talky`.

**Coming from the 1.0 zip?** Open your old Talky once first. It moves your chats to the new location, so the installer doesn't overwrite them.

Talky isn't code-signed yet. If Windows SmartScreen warns, choose **More info → Run anyway**.
